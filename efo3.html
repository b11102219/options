01

AD 曲線向下傾斜的三大效果

總需求曲線（AD）描述每一物價水準下的總需求量。AD 向右下方傾斜，來自三個效果：

財富效果
Wealth Effect：P↓ → 貨幣實質購買力↑ → 消費者更富有 → C↑ → Y↑
利率效果
Interest-Rate Effect：P↓ → MD↓ → r↓ → I↑ → Y↑ 最重要
匯率效果
Exchange-Rate Effect：P↓ → r↓ → 資本外流 → 本幣貶值 → NX↑ → Y↑
核心恆等式：Y = C + I + G + NX
02

流動性偏好理論＋【圖一】貨幣市場均衡

凱因斯的流動性偏好理論：利率 r 調整使貨幣供給（MS）與貨幣需求（MD）達到均衡。

假設

預期通膨率固定；家戶資產只有兩種——貨幣（流動性高、無利息）與債券（流動性低、有利息）。

MS
由央行決定，不受 r 影響 → 垂直線
MD
r↓ → 持有貨幣機會成本↓ → 需求量↑ → 向右下傾斜

影響 MD 移動的變數

Y 上升
交易需求增加 → MD 整條右移
P 上升
每筆交易需更多名目貨幣 → MD 整條右移
r 變動
沿著 MD 移動（不是移動整條曲線）
【圖一】貨幣市場均衡

MS（貨幣供給）：垂直線。由央行透過公開市場操作決定，與利率無關。

MD（貨幣需求）：向右下傾斜。利率越低 → 持有貨幣的機會成本越低 → 需求量越大。

均衡點 E：MS = MD 決定均衡利率 r*。
若 r > r* → 貨幣供給過剩 → 人們買債券 → 債券價格↑、r↓ → 回到 r*。
若 r < r* → 貨幣需求過剩 → 人們賣債券 → 債券價格↓、r↑ → 回到 r*。

03

利率效果＋【圖二】AD 斜率的來源

利率效果是連結貨幣市場與商品市場的核心機制，也是 AD 曲線向下傾斜的最重要原因。

【圖二】利率效果：物價水準下降如何增加需求量

完整傳導鏈（由左圖到右圖）：

① 物價水準從 P₁ 下降到 P₂

② 左圖：每筆交易需要的名目貨幣減少 → MD 從 MD₁ 左移到 MD₂

③ 左圖：MS 不變，新均衡利率從 r₁ 降到 r₂

④ 右圖：r↓ → 投資 I 增加 → 需求量從 Y₁ 增加到 Y₂

⑤ 這就是沿著 AD 曲線從 A 點移動到 B 點（不是 AD 移動，是沿線移動）

04

貨幣政策影響 AD＋【圖三】緊縮貨幣政策 貨幣政策

Fed 透過公開市場操作調整 MS，目標是聯邦基金利率。

擴張性貨幣政策

Fed 買入債券→ MS↑→ r↓→ I↑→ AD 右移→ Y↑

緊縮性貨幣政策

Fed 賣出債券→ MS↓→ r↑→ I↓→ AD 左移→ Y↓
【圖三】緊縮貨幣政策：Fed 減少 MS

分析步驟（緊縮貨幣政策）：

① Fed 賣出政府債券 → 收回市場上的貨幣 → MS 從 MS₁ 左移至 MS₂

② 左圖：MS 減少，但 MD 不變 → 貨幣市場超額需求 → r 從 r₁ 上升到 r₂

③ r↑ → 借貸成本上升 → 企業投資 I 減少、消費者耐久財購買減少

④ 右圖：在每個物價水準下，需求量都減少 → AD 整條左移（AD₁ → AD₂）

⑤ 同一 P₁ 下，Y 從 Y₁ 減少到 Y₂

⚠ 關鍵區分：利率效果＝沿著 AD 移動；貨幣政策＝整條 AD 移動。

政策應用練習
事件短期影響Fed 應如何穩定產出
國會削減 GAD↓ → Y↓增加 MS、降低 r
股市繁榮AD↑ → Y↑(超過自然率)減少 MS、升高 r
油價飆升AS↓ → Y↓增加 MS、降低 r
05

利率目標、零利率下界與流動性陷阱 貨幣政策

為何以利率為操作目標？

MS 難以精確衡量，MD 隨時波動。若死守 MS 固定 → 利率和產出劇烈波動。Fed 改以聯邦基金利率為目標，每天調整 MS 配合 MD 變動，維持利率穩定。兩種描述等價。

零利率下界（Zero Lower Bound）

流動性陷阱：名目利率已降至 ≈ 0 → 傳統貨幣政策失效 → AD、Y、就業被困在低水準。

替代工具

前瞻引導
Forward Guidance：央行承諾長期維持低利率 → 穩定預期 → 鼓勵投資
量化寬鬆
QE：央行購買房貸、公司債、長期國債 → 直接壓低長期利率（Fed 2008 年後大規模使用）
06

財政政策方向與基本邏輯 財政政策

擴張性
G↑ 和/或 T↓ → AD 右移 → Y↑
緊縮性
G↓ 和/或 T↑ → AD 左移 → Y↓

但 AD 最終移動量受乘數效果（放大）與排擠效果（縮小）共同決定。

07

乘數效果＋【圖四】乘數效果圖解 財政政策

G 增加 $1 → 收到的人花掉 MPC 部分 → 又成為他人收入 → 再花 → 循環往復 → 最終 Y 增加遠大於 $1。

邊際消費傾向
MPC = ΔC ／ ΔY
支出乘數
乘數 = 1 ／ (1 − MPC)

公式推導

Y = C + I + G + NX（恆等式）
ΔY = ΔC + ΔG　（ΔI = ΔNX = 0）
ΔC = MPC × ΔY 代入 →
ΔY = MPC × ΔY + ΔG
ΔY(1 − MPC) = ΔG

ΔY = [1／(1−MPC)] × ΔG

MPC乘數G↑ $20b → Y↑
0.52$40b
0.754$80b
0.85$100b
0.910$200b
【圖四】乘數效果：G 增加 $2b 的 AD 移動

讀圖步驟：

① G 增加 $2b → AD₁ 初始右移 $2b 到 AD₂（藍→綠虛線）

② Y 增加 → 家戶所得增加 → 消費 C 增加 → AD 再進一步右移到 AD₃（綠虛線→紅色）

③ 總移動量 = 初始 $2b + 乘數效果的部分 = [1/(1−MPC)] × $2b

④ 例如 MPC=0.8 → 總移動 = 5 × $2b = $10b

重要：乘數效果適用於 GDP 所有組成部分（C、I、G、NX）的變動，不僅限於 G。
08

排擠效果＋【圖五】排擠效果圖解 財政政策

擴張性財政政策增加產出 → 推升利率 → 民間投資被壓縮 → 部分抵消 AD 的增加。

【圖五】排擠效果：G↑ $2b 時利率上升抵消部分需求

分析步驟：

① G↑ $2b → AD₁ 右移 → Y↑ → 所得增加 → 貨幣需求 MD 增加

② 左圖：MS 不變但 MD 右移（MD₁→MD₂）→ 利率從 r₁ 上升到 r₂

③ r↑ → 企業投資 I 減少 → 部分需求被「排擠」掉

④ 右圖：若無排擠，AD 會移到 AD₃（綠虛線）；但排擠使 AD 只到 AD₂（紅色實線）

⑤ 最終結果：Y₁ → Y₂（而非 Y₃），排擠效果削減了部分財政擴張的效果

淨效果排序： 初始 ΔG < 實際 ΔY（含排擠） < 乘數×ΔG（無排擠）

09

減稅的效果 財政政策

減稅 → 可支配所得↑ → C↑ → AD 右移。移動幅度同樣受乘數與排擠效果影響。

永久減稅
家戶預期長期所得增加 → 大幅增加 C → AD 影響較大
暫時減稅
家戶知道不持續 → 多儲蓄 → AD 影響較小
減稅 vs. 增加 G 的比較：同樣 $1，G↑ 直接讓 AD 增加 $1；但減稅 $1 → 家戶只消費 MPC×$1（如 MPC=0.8 則 $0.8），初始推力較小。
10

財政政策與總供給 財政政策

減稅的供給面效果

降低稅率 → 勞動者工作誘因增加 → 勞動供給↑ → 產出供給↑ → AS 右移。此觀點的擁護者稱為「供給學派」（Supply-siders）。

政府支出的供給面效果

例：政府投資道路 → 企業生產力提高 → AS 右移。此效果主要在長期顯現。

11

主動穩定政策正反辯論

✅ 支持主動穩定

凱因斯：動物本能（animal spirits）→ AD 波動 → 產出就業不穩定。加上海外景氣、股市等外部衝擊，政府不介入 → 經濟痛苦。

主張：GDP < 自然率 → 擴張政策；GDP > 自然率 → 緊縮政策。

❌ 反對主動穩定

時間落後（Time Lag）：貨幣政策 ≥ 6 個月；財政政策需立法 → 數月至數年。等生效時經濟已改變，政策反而加劇波動。

主張：聚焦長期目標（經濟成長、低通膨），不要頻繁干預。

12

自動穩定因子（Automatic Stabilizers）

無須刻意立法，經濟衰退時自動啟動的財政機制：

稅制
衰退 → 所得↓ → 稅額自動↓ → 可支配所得不至大跌 → 支撐 C 與 AD
移轉支出
衰退 → 失業增加 → 失業保險、社會救助自動↑ → 支撐家戶所得 → 支撐 AD
優勢：不需立法、不需等待政治程序，反應速度遠比主動政策快。

產出變動（無排擠）

⚠ 易混淆點＆常見陷阱

1. 沿線移動 vs. 整條移動：P 變動 → 沿著 AD 移動（利率效果）；MS 或 G/T 變動 → 整條 AD 移動。

2. 乘數對所有組成部分都適用：不只 G 變動，NX、I、C 的外生變動都會透過乘數放大。

3. 排擠效果只出現在財政政策：因為是 G↑→Y↑→MD↑→r↑→I↓ 的回饋迴路。貨幣政策本身就在控制 r，不存在排擠。

4. 減稅初始推力 < 等額增加 G：G↑$1 直接進入 AD；T↓$1 只有 MPC×$1 進入 AD。

5. 零利率下界：傳統貨幣政策失效 ≠ 貨幣政策完全無用（還有 QE 和前瞻引導）。

6. 自動穩定因子 vs. 主動政策：前者自動啟動、無時間落後；後者需刻意決策、有落後問題。
